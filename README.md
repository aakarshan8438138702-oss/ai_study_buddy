# 📚 Study Buddy

A beginner-friendly study app built with Python and Streamlit. Save notes, make flashcards and test yourself with quizzes.

🔗 **Live app:** https://aistudybuddy-yb3cfe2kzfvh4fqddujwju.streamlit.app/

## Features
- 📝 **Notes:** create, search, edit and delete
- 📚 **Flashcards:** question/answer cards with show/hide answer
- 🧠 **Quizzes:** fill-in-the-blank questions from your notes, or pick-the-answer questions from your flashcards, with scoring
- 💾 **Storage:** notes and flashcards saved as JSON files, with backup and restore on the dashboard

## Note on the quiz
The quiz is generated with simple Python rules. It does not use an AI model.

## Limitations
Streamlit Cloud can erase saved files when the app restarts or redeploys, so download a backup from the Dashboard regularly.

## Run it locally
1. Install Python 3.9 or newer
2. Run: pip install streamlit
3. Run: streamlit run app.py
